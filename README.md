# 영화 좌석 예매 프로그램

Java와 Oracle Database(JDBC)를 이용한 콘솔 기반 영화 좌석 예매 프로그램입니다.

## 1. 프로젝트 구성

- 상영관: 1관
- 영화: 3개
- 좌석: 영화별 25석 (A1~E5)
- 예매 인원: 1명 고정

영화 및 상영 정보는 DB에 등록된 데이터를 기준으로 합니다.

## 2. 데이터베이스 설정

1. Oracle Database에 접속합니다.
2. `영화예매 DB 초기화용.sql` 파일을 실행하여 테이블, 시퀀스 및 초기 데이터를 생성합니다.
3. Eclipse 프로젝트의 `src` 폴더에 있는 `db.properties.example` 파일을 참고하여 `db.properties` 파일을 생성합니다.
4. 자신의 Oracle 접속 정보에 맞게 설정합니다.

```properties
db.url=jdbc:oracle:thin:@localhost:1521:xe
db.id=Oracle계정
db.pw=Oracle비밀번호
```

`db.id`와 `db.pw`는 실제 Oracle 계정 정보로 변경해야 합니다.

**주의:** DB 초기화 SQL은 기존 테이블과 시퀀스를 삭제한 후 다시 생성하므로 기존 데이터가 있는 경우 주의해야 합니다.

## 3. Eclipse 프로젝트 실행

1. Eclipse에서 프로젝트를 가져옵니다.
2. Oracle JDBC 드라이버(`ojdbc8.jar`)를 프로젝트 Build Path에 등록합니다.
3. `src/db.properties` 파일의 설정을 확인합니다.
4. `MovieMain.java`를 실행합니다.

## 4. 주요 기능

1. 전체 영화 조회
2. 상영중인 영화 검색
3. 영화 좌석표 조회
4. 영화별 남은 좌석 수 조회
5. 영화 예매
6. 예매 티켓 취소
7. 예매티켓 전체 조회
8. 예매한 티켓 검색
9. 많이 예매한 영화 조회
10. 오전 영화 조회
11. 오후 영화 조회
12. 프로그램 종료

## 5. 영화 예매 방법

1. 메인 메뉴에서 `5번 영화 예매`를 선택합니다.
2. 예매할 영화 번호를 입력합니다.
3. 좌석표에서 비어 있는 좌석을 확인합니다.
4. 예매할 좌석의 행과 열을 입력합니다. (예: `A 1`)
5. 선택한 좌석이 `■`로 표시된 좌석표를 확인합니다.
6. 예매 확인 화면에서 `Y`를 입력하면 예매가 확정됩니다.
7. 예매 완료 후 예매 번호가 출력됩니다.

### 좌석 표시

- `□` : 빈 좌석
- `■` : 예매된 좌석 또는 현재 선택한 좌석

선택한 좌석은 예매 확정 전까지 DB에 저장되지 않으며, `Y`를 입력하여 예매를 확정하면 DB에 저장됩니다.
